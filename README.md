# RAHMEEN — A wardrobe in bloom

A responsive editorial ecommerce demonstration using HTML, CSS and JavaScript modules. No install or build is required.

## Preview

Run `npm run dev` in this directory, then visit http://127.0.0.1:4173. Run `npm run check` for JavaScript syntax validation.

## Editing

- `dist/catalogue.js`: editable sample products, PKR prices, categories, sizes and material descriptions.
- `dist/main.js`: homepage, editorial sections, navigation, newsletter demonstration and information pages.
- `dist/commerce.js`: collection filters, product galleries, search, size selection, wishlist and bag.
- `dist/styles.css` and `dist/commerce.css`: responsive design, reduced-motion behavior and shopping layouts.
- `dist/assets/`: campaign photos, original logo and supporting flower graphics.

## Before commercial launch

The supplied original logo is preserved at `dist/assets/logo.png` and displayed unchanged. The brand coral `#F8704B` was sampled from its dominant opaque pixel colour. Supporting flower graphics interpret its four rounded petals.

All photographic assets are generated concept imagery. Products, prices and measurements are demonstration content and are not real inventory. Replace with verified photography, product data and measurements before accepting orders. The site intentionally contains no reviews, invented brand history or shipping promises.

Bag and wishlist persist in browser local storage. Newsletter submission is explicitly a preview and does not collect subscriptions. The checkout preview does not process orders or payments. Connect verified inventory, payment, fulfillment and email services before launch, and supply contact details, official social URLs and approved policies.

Khaadi's official storefront (https://pk.khaadi.com/) informed collection discovery and merchandising patterns only. RAHMEEN's layout, copy and campaign visuals are original.
